# Johto

Dados da região de Johto (insígnias 1–8), conforme HeartGold/SoulSilver.

Só **dados e scripts de evento**: mapas, encontros, treinadores, itens, eventos, textos.
Nenhum código C++ específico da região. Comportamento novo vira um comando genérico em `game/events/`.

Primeira fatia jogável planejada: New Bark Town → Violet City (ver `docs/roadmap.md`, M6).
